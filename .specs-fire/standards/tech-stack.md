# Tech Stack

## Overview

NamehAmal is a minimal, local-first time tracking application. It runs as a single Next.js (App Router) server with a local SQLite database file — no auth, no cloud sync, no external services. The entire app (UI + API + data layer) lives in one monolith.

## Core Technologies

### Language

**Primary**: TypeScript
**Version**: 6.0.3

### Framework

**Framework**: Next.js (App Router)
**Version**: 16.2.4
**Rationale**: App Router provides server components, route handlers, and URL-stored state primitives that fit a local-first single-user app.

### Runtime

**Runtime**: Node.js (via Bun)
**Version**: LTS (Bun runtime / Node compat)

## Data Layer

### Database

**Type**: Embedded SQL
**Database**: SQLite
**Version**: better-sqlite3 12.4.1

### ORM / Data Access

**Tool**: Prisma 7.8 with `@prisma/adapter-better-sqlite3` driver adapter
**Rationale**: Type-safe schema-first access; the driver adapter keeps queries local and synchronous against the embedded SQLite file. Client is generated into `app/generated/prisma`.

### Caching

Not configured. Local-first single-user app; no shared cache layer needed.

## API Layer

### API Style

**Style**: Next.js Route Handlers (`app/api/*/route.ts`) returning JSON; full CRUD for categories and sessions, plus a live tracker draft API.

### Documentation

**Tool**: README + Prisma schema doc comments (no OpenAPI spec configured).

## Frontend

### UI Framework

**Framework**: React
**Version**: 19.2.4

### Styling

**Approach**: Tailwind CSS 4 (`@tailwindcss/postcss`)

### State Management

**Solution**: URL search params for shareable/refresh-safe filters (Dashboard, Stats); React state for local UI; server components fetch data directly. A lightweight event bus (`app/dashboard/active-timer-refresh-bus.ts`) coordinates cross-component refresh.
