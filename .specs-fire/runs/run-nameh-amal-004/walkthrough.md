# Implementation Walkthrough: Phase End Alert

## Summary

Added a global phase-completion alert: a dismissible modal and Web Audio chime triggered when a Pomodoro phase ends (naturally or via Skip). Mounted inside `PomodoroProvider` so it works on every route.

## Structure Overview

`PomodoroProvider` subscribes to engine phase transitions → `PomodoroPhaseAlert` listens via `subscribePhaseComplete` → shows modal + plays sound.

| Decision | Choice | Rationale |
